# Security Policy

## Supported Versions

This project is maintained as a personal learning and portfolio project. There are currently no officially supported versions or long-term maintenance releases.

| Version | Supported |
|---------|-----------|
| Latest | ✅ Best effort |
| Older versions | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability, please open a GitHub Issue with enough detail to reproduce the problem.

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- The potential impact.
- Any suggestions for a fix (optional).

If the issue contains sensitive information, you may instead contact me through my GitHub profile.

## Security Updates

This project does **not** follow a formal security update schedule.

Security fixes, if needed, will be addressed on a best-effort basis, and there is no guarantee regarding response times or future maintenance.

## Disclaimer

Adventure-Game is an educational and portfolio project intended for learning purposes. It should not be considered production-ready software and should be used at your own discretion.
