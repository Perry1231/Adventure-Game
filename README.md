# Adventure-Game
Text-Based Adventure Game


Adventure Game is a console-based adventure game written in C++. The player explores different locations, interacts with the environment, makes decisions, and progresses through the story by completing various challenges and objectives.

Features

- Interactive text-based gameplay
- Multiple locations to explore
- Decision-based progression system
- Inventory and item interaction mechanics
- Dynamic game events and challenges
- User-friendly console interface
- Object-Oriented Programming (OOP) design
- Clean and modular C++ code structure

Technologies Used

- C++
- Standard Template Library (STL)
- Object-Oriented Programming principles

Getting Started

Requirements

- C++ compiler with C++17 support (GCC, Clang, or MSVC)
- CMake (optional)

Installation

1. Clone the repository:

git clone https://github.com/Perry1231/Adventure-Game.git

2. Navigate to the project directory:

cd Adventure-Game

3. Compile the project:

g++ *.cpp -o AdventureGame

4. Run the game:

./AdventureGame

Purpose

This project was created to practice C++ programming, object-oriented design, game logic implementation, and software development best practices.
